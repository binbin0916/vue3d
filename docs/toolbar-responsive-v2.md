# 底部工具栏适配方案（全新设计）

> 忽略所有历史方案，从零设计

---

## 设计思路

**核心问题**：同一套工具栏要适配 320px 手机到 2560px 4K 显示器。

**解法**：放弃「一套样式 + 媒体查询」的思路，改用 **CSS Container Query** —— 工具栏根据自身宽度自适应，而非根据视口宽度。这样无论工具栏被放在什么容器里，都能正确缩放。

---

## 布局方案

### PC 端（≥768px）

```
┌──────────────────────────────────────────────────────────────┐
│  [面包屑]  │  [移动] [视角>] [测量>] [标注>] [剖切>] [材质>] [导出>]  │  [关闭]  │
└──────────────────────────────────────────────────────────────┘
  固定左侧      自适应中间（可滚动）                      固定右侧
```

- 面包屑：左侧固定区域，带竖线分隔
- 工具按钮：中间自适应，内容溢出时**两端渐变遮罩**暗示可滚动
- 关闭按钮：右侧固定（仅子菜单时显示）
- 颜色选择器：紧跟在工具按钮后面（激活颜色工具时显示）

### 移动端（<768px）

```
┌─────────────────────────────────────────┐
│  [移动] [视角>] [测量>] [剖切>] [材质>]  │
└─────────────────────────────────────────┘
  仅图标，无文字标签，更紧凑
```

- 隐藏面包屑（改为顶部浮动提示或完全省略）
- 工具按钮仅显示图标，不显示文字
- 整体更紧凑，减少内边距

## 自适应策略

### CSS Container Query（推荐）

```css
.toolbar-panel {
  container-type: inline-size;
  container-name: toolbar;
}

/* 默认：宽屏（图标 + 文字） */
.toolbar-item .item-label {
  display: inline;
}

/* 窄容器（<480px）：仅图标 */
@container toolbar (max-width: 480px) {
  .toolbar-item .item-label {
    display: none;
  }
  .breadcrumb-nav {
    display: none;
  }
}
```

### 优势

| 对比维度 | 媒体查询 | Container Query |
|----------|----------|-----------------|
| 依赖 | 视口宽度 | 容器自身宽度 |
| 灵活性 | 固定断点 | 连续自适应 |
| 可复用性 | 仅当前页面 | 任意容器内可用 |
| 精确度 | 粗糙 | 精确 |

## 滚动处理

### 方案：渐变遮罩 + 触摸滑动

**不使用滚动按钮**，改为：

1. **两端渐变遮罩** — 内容溢出时，左右两侧出现半透明渐变，暗示可滚动
2. **原生触摸滚动** — 移动端直接左右滑动
3. **鼠标滚轮** — PC 端支持鼠标横向滚轮

```
┌──────────────────────────────────────────────────┐
│ ░░[移动] [视角>] [测量>] [标注>] [剖切>] [材质>]░░ │
└──────────────────────────────────────────────────┘
  ↑ 左侧渐变遮罩              右侧渐变遮罩 ↑
  （左侧有内容被隐藏时显示）   （右侧有内容被隐藏时显示）
```

### 渐变遮罩实现

```css
.toolbar-items {
  position: relative;
}

/* 左侧遮罩 */
.toolbar-items::before {
  content: '';
  position: absolute;
  left: 0; top: 0; bottom: 0;
  width: 24px;
  background: linear-gradient(to right, white, transparent);
  z-index: 1;
  pointer-events: none;
  opacity: 0;
  transition: opacity 0.2s;
}

/* 有左侧滚动时显示 */
.toolbar-items.scrolled-left::before {
  opacity: 1;
}

/* 右侧遮罩同理 */
.toolbar-items::after { ... }
```

## 尺寸规范

### 流式缩放（clamp）

所有尺寸使用 `clamp(min, preferred, max)` 实现连续缩放：

| 元素 | 公式 | 360px | 768px | 1440px |
|------|------|-------|-------|--------|
| 面板内边距 | `clamp(6px, 1vw, 12px)` | 6px | 8px | 12px |
| 面板圆角 | `clamp(8px, 1vw, 12px)` | 8px | 8px | 12px |
| 按钮内边距 | `clamp(6px, 0.8vw, 12px)` | 6px | 6px | 12px |
| 按钮圆角 | `clamp(6px, 0.6vw, 8px)` | 6px | 5px | 8px |
| 图标容器 | `clamp(28px, 3vw, 36px)` | 28px | 23px | 36px |
| 图标 SVG | `clamp(14px, 1.5vw, 18px)` | 14px | 12px | 18px |
| 字号（有标签） | `clamp(12px, 1.2vw, 14px)` | 12px | 9px | 14px |
| 字号（仅图标模式） | — | 隐藏 | 隐藏 | 隐藏 |

### 断点（仅用于极端场景的微调）

| 断点 | 用途 |
|------|------|
| `< 480px` | 隐藏面包屑、隐藏文字标签 |
| `≥ 480px` | 显示文字标签 |
| `≥ 768px` | 显示面包屑 |

## 交互状态

### 工具按钮

| 状态 | 背景 | 文字 | 边框 |
|------|------|------|------|
| 默认 | 透明 | `#606266` | 无 |
| hover | `#f5f7fa` | `#303133` | 无 |
| active | `#f0f2f5` | `#909399` | 无 |
| activated | `#ecf5ff` | `#409EFF` | `inset 0 0 0 1px rgba(64,158,255,0.2)` |

### 滚动遮罩

| 状态 | 左侧遮罩 | 右侧遮罩 |
|------|----------|----------|
| 无滚动 | 隐藏 | 隐藏 |
| 左侧有隐藏内容 | 显示（白色渐变） | 隐藏 |
| 右侧有隐藏内容 | 隐藏 | 显示（白色渐变） |
| 两侧都有隐藏内容 | 显示 | 显示 |

## 动效

| 元素 | 动效 | 时长 |
|------|------|------|
| 菜单切换 | `translateY` + `opacity` | 300ms ease-out |
| 按钮 hover | 背景色渐变 | 200ms |
| 按钮 active | `scale(0.97)` | 150ms |
| 激活态 | 背景 + 边框渐变 | 200ms |
| 渐变遮罩 | `opacity` | 200ms |
| 入场动画 | `translateY(8px)` + `opacity` | 350ms staggered |

## 与现有方案的关键差异

| 维度 | 现有方案 | 新方案 |
|------|----------|--------|
| 自适应方式 | 媒体查询（视口） | Container Query（容器） |
| 滚动处理 | 左右箭头按钮 | 渐变遮罩 + 原生滚动 |
| 标签显示 | 始终显示 | 宽容器显示，窄容器隐藏 |
| 面包屑 | 始终显示 | 窄容器隐藏 |
| 尺寸缩放 | 固定值 + 断点 | `clamp()` 连续缩放 |
| 移动端优化 | 缩小间距 | 完全不同的布局策略（仅图标） |
